# bapTV guide screenshots

Images shown by the app's introduction and "Did you know?" tips, fetched from
`https://raw.githubusercontent.com/depablo/bapTV/tour/<language>/<name>.webp`
(see `Illustrations.kt` on `main`). They are only illustrations: the app shows
the text alone when an image is missing or cannot be downloaded.

- `pl/` – Polish interface, `en/` – English (used for every other language)
- 960×540 WebP; TV screens come from the set-top box, phone screens from the
  phone remote page in a 412 px wide browser, centred on the app background
- Names used by the app: player, player-info, pause, guide,
  channel-list-categories, menu-phone-remote, menu-record, menu-numbering,
  menu-report, phone-home, phone-iptv, phone-iptv-check, phone-iptv-mine,
  phone-signal, hbbtv (not provided – broadcaster content)

This branch has no history in common with `main`; replacing a file here
updates the app's illustrations within a week (the app caches them).
